# Aakash Institute – AI Voice Agent

## Project Overview
An AI-powered voice assistant built using ElevenLabs, designed to handle incoming calls for Aakash Institute and provide automated responses to student queries.

## Features
- AI-powered voice conversations
- Handles incoming calls
- Answers student queries
- Natural voice interactions
- Automates basic communication

## Technology Stack
- ElevenLabs
- Conversational AI
- AI Voice Agents

## Objective
To demonstrate how AI voice agents can improve communication and automate incoming call handling in the education sector.
